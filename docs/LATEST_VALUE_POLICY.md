# 国別サイトの最新版表示方針

国別ダッシュボードの利用者向け3ページでは、年を選ばせない。地域診断は、選択地域について**指標ごとに取得・確認できた最も新しい値**を表示し、値の直近にその出典年・期間を表示する。教育が2022年、水が2024年なら、同じ画面でそれぞれの値に`2022`、`2024`を付ける。古い共通年へ揃えるために新しい値を隠さず、全国値を地方値へ代用しない。

テーマ診断の地域間比較は、一つの指標について比較対象階層に観測がある最も新しい共通年を自動採用する。順位、中央値、地図、比較CSVはその同じ年だけを使う。選択地域の最新版が比較年と異なる場合は、選択地域の最新版と年を別に示し、同年順位ではないことを明記する。

Development Plan Materialsの画面、根拠CSV、Markdown、HTML、DOCXは、指標ごとの最新版と年を収録する。計画期間、会計年度、四半期、評価基準日は統計年と別の項目として原文どおり保持する。

過去年のセレクター、時系列グラフ、履歴CSVへの導線は国別3ページに置かない。過去の観測行、原本、取得receipt、変換記録は、再現・監査・更新判定のため`data`、`raw`、`evidence`とData Registerに保持してよい。利用者向け表示を簡潔にすることと、過去データを削除することは別である。

世界・大陸・広域版は集計と比較の契約が異なるため、従来どおり明示期間を扱える。国別版へ移動した時点で、その国の最新版表示方針へ切り替える。

## 納品確認

- 地域診断の各値に実際の出典年がある。
- 指標間で年が違っても、それぞれの最新版を表示する。
- 国別3ページに年セレクター、過去年への切替、時系列グラフ、履歴CSVボタンがない。
- テーマ診断の順位・地図・中央値・比較CSVは一指標・一階層・一共通年で一致する。
- 選択地域の最新版と比較年が異なる場合、その差を画面で説明する。
- 診断3形式と計画4形式で、地域、指標、値、単位、年、出典が画面と一致する。
- 古い`?period=`を含む国別URLを開いても過去年表示へ戻らず、現在の最新版へ正規化される。
