# 汎用AIが国別版を薄いまま完成扱いしないための確認

## 何が起こりやすいか

国名だけから作る作業では、AIが最初に取得しやすい全国系列と人口ファイルだけで画面を埋め、ローカルサーバーが起動すると完成と判断しやすい。ラオスの初期試作を監査したところ、次の問題が同時に起きた。

- 18州・148郡を登録したが、郡で使える地方指標は2024年人口推計の6本だけだった。
- 人口CSVには男女別5歳階級があったが、0–14、15–64、65歳以上へまとめた列しか採用せず、人口ピラミッド等に使える原列を捨てた。
- OPHIの取得済みExcelには州別の貧困、教育、栄養、乳幼児死亡、調理燃料、衛生、水、電力、住宅、資産等の多数の数値列があったが、3指標しか採用しなかった。
- 2017年の州別指標を取得済みでも、画面全体を2024年に固定したため「データなし」と表示した。
- 郡を選択できるのにADM2境界を取得せず、大きな空地図を表示した。
- 郡ページを全国WDIカードが占め、同じ「データなし」を繰り返した。
- 日本語UIの中に英語の見出し・説明・行政階層名が大量に残った。
- 全国計画と地方行政法は取得したが、地方計画資料は0件で、地方計画用の完成品とは呼べなかった。
- 地域IDと地域型の大文字小文字・綴りが版の途中で変わり、共有URLが同じ地域へ戻らなかった。
- 取得済み計画資料がある一方で「planning documents — Not collected」とも表示し、台帳間で状態が矛盾した。

これは「ラオスにデータがない」という結論ではない。例えば、[Lao Population and Housing Census 2015](https://lao.unfpa.org/en/publications/results-population-and-housing-census-2015-english-version)には人口、都市・農村、教育、経済活動、障害、住宅等の表があり、Appendix 1のTable P1.1には148郡の人口と都市・道路アクセス別人口がある。[LSIS III provincial snapshots](https://www.unicef.org/laos/reports/lao-social-indicator-survey-iii-lsis-iii-provincial-snapshots)は18州について2023年の保健・教育・子ども・女性・世帯指標を提供している。取得済み原本と公式公開先を十分に確認せず、最初の簡単なファイルで探索を止めたことが主因である。

## 実装前に行う探索

次の順で確認し、一つの経路が使えなくても次へ進む。検索結果ページの存在だけでは確認済みにしない。

1. 統計局の国勢調査目録、最終報告、付表、地域統計書、データポータルとAPI。
2. 計画法が診断を求める各テーマについて、統計局の標本調査と所管省庁の行政統計。
3. MICS、DHS、LSMS等の公式共同調査と、州・県別報告・スナップショット。
4. OCHA/HDXのCOD-PS、COD-AB、施設・人道データ。公式コード・境界版との対応を別途確認する。
5. UNFPA、UNICEF、WHO、UNHCR、ILO、FAO、World Bank等の地域別公表値。
6. IPUMS IHGIS等の再構成表。利用条件と元統計局資料を記録する。

人口、教育、保健・栄養、水・衛生・住宅・エネルギー、生計・貧困・経済、アクセス・インフラ・環境の6分野を必ず監査する。値の掲載を一律に強制するものではない。各分野を「地方値統合済み」「利用可能候補を発見したが未統合」「複数の所在を確認したが利用可能地方値なし」「根拠付きで取得不能」「非該当」に分け、候補発見のまま納品しない。

## 原表を読むときの規則

- Excelは全シート、CSV/APIは全フィールド、PDFは目次・付表・継続表を確認する。
- 数値列ごとに原名、意味、単位、分母、地域粒度、期間、採用指標ID、非採用理由を`evidence/SOURCE_TABLE_INVENTORY.json`へ残す。
- 画面に全列を並べる必要はない。計画に有用な指標へ整理してよいが、落とした列と理由を残す。
- 一つのExcelにないことを、国勢調査全体や国全体に存在しないことへ広げない。
- 発見した利用可能候補を統合しない場合は、ライセンス、地域照合、定義、品質等の具体的理由を記録する。時間切れや実装の手間は完成判定の理由にしない。
- 取得できることと、原本をPublic GitHubで再配布できることを分ける。各sourceの利用条件を確認し、原本を含める、除外する、メタデータだけを置く、の判断を記録する。

## 画面で防ぐこと

- Territorial Diagnosticは選択地域に値があるテーマを先に表示し、各指標の最新版と出典年を示す。年セレクター、過去年への切替、時系列グラフ、履歴CSVを国別3ページへ残さない。
- 全国系列は地方値と分け、地方ページの主内容を全国カードで埋めない。
- Thematic Diagnosticの比較は一指標・自動選択した最新共通年・一地域型を守る。選択地域の最新版が異なる場合は別に示し、比較行へ混ぜない。
- 選択可能階層に図形がなければ、大きな空地図を置かず短い不足表示にする。未結合IDを保存する。
- 表示言語ごとにナビゲーション、見出し、操作説明、状態文を通して確認する。原資料の固有名称を除き、意図しない言語混在を残さない。
- 再生成前後で地域ID、公式コード、地域型、共有URLの復元を確認する。別IDへの無言のフォールバックを合格にしない。

## 完成判定

`verify-delivery.mjs`は次を追加確認する。

- `SOURCE_TABLE_INVENTORY.json`で全採用指標が原フィールドへ追跡でき、非採用数値列にも理由があり、各sourceの再配布判断が記録されている。
- `THEME_COVERAGE.json`で6分野の探索が終わり、`candidate_found_not_integrated`が残っていない。
- 全選択可能階層について地域数・図形結合数が実データと一致し、図形不足時の表示を確認した。
- 指標別最新版と出典年、国別3ページでの過去年UI不在、地方画面での全国文脈の分離、表示言語の混在確認を実ブラウザーで記録した。

ゲート通過は内容の真実性を自動保証しない。AIは最後に「取得した原本に、まだ未棚卸しのシート・付表・数値列はないか」「検索で見つけた地方データ候補を実装都合で放置していないか」「この画面は地方計画担当者が実際に使えるか」を反証的に確認する。
