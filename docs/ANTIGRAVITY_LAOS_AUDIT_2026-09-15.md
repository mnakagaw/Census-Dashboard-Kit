## 問題一覧

### 1. トップページの役割が弱い

- 国名、入口カード、件数、地域選択、出典一覧を再掲するだけで、地域診断を始める前に一画面増えている。
- 初心者が最初に必要とするのは対象地域の診断である。

対処:

- `/`で地域診断を直接表示する。
- 「ホーム」メニューを削除する。
- ヘッダーの`Census Dashboard`を押すと、クエリを整理して全国の地域診断へ戻す。

### 2. 計画ページ名が国の制度サイトのように見える

- `ラオス地方社会経済開発計画（SEDP）策定基礎資料`というメニュー名は、生成サイト自体がSEDP制度の主体であるように見える。
- サイト内に`Official`、`公式`、`law-aligned Word`などの強い表現が多い。

対処:

- 共通メニュー名を`計画資料・リンク`（英語: `Planning materials and links`）にする。
- 出典資料の原題や発行主体を示す場合を除き、サイト自身の説明には`Official`や`公式`を使わない。
- `確認済み`も、何を確認したかを伴う`source-checked`、`本文取得済み`、`出典照合済み`等へ分ける。

### 3. 「データなし」と下位地域の色付き地図が同時に出る

- 選択地域全体の値がない指標でも、下位地域には値があり、色付き地図と比較表が表示される。
- 現在の`データなし`は「選択地域全体の値がない」のか「下位地域にも値がない」のかを区別しない。

対処:

- 表示を`選択地域全体の値なし`へ変更する。
- 下位地域に値がある場合は、地図の前に`下位地域 N/M件の値を表示中。選択地域全体の値ではない`と表示する。
- 下位地域にも値がなければ、空の地図、凡例、全件欠測表を画面では表示しない。

### 4. データがあるテーマまで閉じる

- テーマの開閉判定が選択地域全体の値だけを見ている。
- 選択地域全体が欠測でも下位地域比較に値があるテーマが閉じられ、開くと色付き地図が現れる。

対処:

- 選択地域全体または下位地域比較のどちらかに値があれば、テーマを初期表示で開く。
- 見出しに`選択地域値 X/Y・下位地域データあり`を表示する。
- 両方に値がないテーマだけ閉じる。

### 5. 値が0件の比較階層を選べる

- テーマ診断で、選択指標のADM2値が`0 / 148`でもADM2を比較階層として選べる。
- 境界があるため灰色地図が大きく表示され、分析できるように見える。

対処:

- 選択指標について観測値が1件以上ある階層だけを比較階層の候補にする。
- 指標変更時に現在の階層が0件なら、値がある最初の階層へ自動的に切り替える。
- ADM2台帳と境界は地域・資料検索に残す。統計比較が可能であるとは表示しない。
- 階層ごとの地域数、境界数、観測値数、値がある指標数を納品記録に残す。

### 6. 人口ピラミッドがない

- 取得済みデータには男女合計等があるが、画面用の年齢階級×男女系列がない。
- DDPTを基準とする地域診断の基本表示として不足している。

対処:

- 国勢調査の年齢階級×男女表を優先取得する。
- `population_pyramids`に地域、年、単位、source、年齢階級別男女値を保持し、地域診断上部に表示する。
- 全国しか取得できない場合は全国画面だけに出し、地方値へ転用しない。
- 取得不能の場合は、確認した表・URL・取得不能理由を記録しない限り完成扱いにしない。

### 7. Wordが計画書の下書きに見える

- 旧Wordは地域名＋Development Planという表題で、計画書の下書きに見える。
- 法・ガイドの章立ての下に汎用の入力指示だけが並び、取得済み統計から書ける本文が入っていない。
- `undefined — partial with statute: undefined`が残るページがある。
- `Diagnóstico Territorial`が独立した必須内容として入っていない。

対処:

- Word名と文書タイトルを`Diagnóstico para el Plan de Desarrollo Municipal — 地域名`にする。
- 文書の性格を市開発計画用の診断・基礎資料とし、計画案、草案、承認待ち文書の体裁にしない。
- 法・ガイドに基づくインデックスを保持する。
- `Diagnóstico Territorial`を必須章として追加し、全テーマの最新版、値、単位、年、状態、出典を掲載する。
- 各法定インデックス章に`indicator_ids`を対応させ、取得済み値から事実記述と表を自動生成する。
- `undefined`、`TODO`、`TBD`、`REPLACE_WITH`、旧汎用入力文が残るWordを納品ゲートで不合格にする。
- 全ページを隔離レンダラーでPNG化し、PNG実体とページ数を納品証拠にする。

### 8. 法律資料の誤登録を検出できなかった

- `lao-law-local-admin-2015`は名称上は地方行政法だが、URL、`raw_path`、SHA-256が2015年国勢調査PDFと同一である。
- 同じ国勢調査PDFを`law`と`census`の二つの役割へ登録し、法律の条文確認済みとして扱っている。

対処:

- `law`、`census`、`international`間でsource ID、URL、raw path、SHA-256の重複を禁止する。
- 法規sourceは文書名、番号、発行主体、日付、表紙または標題頁、条・章・頁を記録した`LEGAL_SOURCE_AUDIT.json`を必須にする。
- sourceの宣言SHA-256と保存ファイルの実SHA-256を照合する。
- 国勢調査PDFの題名を法律名へ変更しただけの記録は不合格にする。

### 9. `collection.status: complete`が過大

- 現在は`complete`だが、人口ピラミッドなし、ADM2は7/20指標、地域別計画資料なし、法律source誤登録がある。
- `complete`の意味が機械的に検査されていない。

対処:

- 未取得テーマ、値0件の階層、計画資料不足、法律監査未合格、人口ピラミッド未取得が一つでもあれば`complete`を拒否する。
- 利用可能なサイトとしての完成と、データ収集の完全性を別々に記録する。

### 10. 生成成功と完成品が混同された

- `create-country`、`npm run check`、`npm test`、`validate-country`の成功だけで、実データ・法律・Word・ブラウザ表示の正しさを保証できない。
- 旧`DELIVERY.json`はAIが自己申告した真偽値とファイル存在を主に確認し、本文の一致を検査していない。

対処:

- `site/data/dashboard.json`と正本`data/dashboard.json`の意味上の一致を検査する。
- 生成済みJavaScriptの構文検査を行う。
- `/`、`/territorial/`、`/thematic/`、`/planning/`の実ブラウザ結果を別々に記録する。
- Word本文、法律source、人口ピラミッド、階層別観測数を機械検査する。
- `verify-delivery.mjs`が合格するまで完成報告を禁止する。

### 11. Antigravityの許可確認が多すぎる

- `git clone`、`node`、`npm run check`、`npm test`、HDX API照会ごとに許可確認が出た。
- 長い`node -e`コマンドを都度生成したため、同じドメインの調査でも許可ルールを再利用しにくい。

対処:

- READMEの冒頭で、プロジェクトのSecurity Presetを`Full Machine`にする場所を画像相当の手順で示す。
- 初回確認では`このプロジェクトで常に許可`を選ぶ対象を説明する。
- API照会、取得、棚卸しをキット内の固定スクリプトへ集約し、毎回異なる`node -e`を作らせない。
- プロンプトに`許可待ちをまとめ、承認済みの固定スクリプトを再利用する`と明記する。

### 12. 作業ディレクトリが散らかる

- キット直下に多数の一時Pythonスクリプトと国別出力が作られた。
- 何がテンプレート本体で、何が一時調査物で、何が納品物か分かりにくい。

対処:

- テンプレートは`kit/`、国別成果物はその兄弟ディレクトリ、途中ファイルは国別成果物内の`work/`へ置く。
- 一時スクリプトをテンプレート直下に作らない。
- READMEのコピペプロンプトを短くし、詳細契約は`START_HERE.md`と固定ワークフローへ委ねる。

## 次回実行の最低受入条件

1. `/`が全国の地域診断として開く。
2. ヘッダーを押すと全国の地域診断へ戻る。
3. ナビゲーションが`地域診断`、`テーマ診断`、`計画資料・リンク`の3つになる。
4. 選択地域全体の欠測と下位地域データを別表示する。
5. 下位地域に値があるテーマは開き、両方空のテーマだけ閉じる。
6. 選択指標で0件の階層を比較候補に出さない。
7. 人口ピラミッドを表示するか、取得不能の根拠を残す。
8. Word名が`Diagnóstico para el Plan de Desarrollo Municipal`で、`Diagnóstico Territorial`、最新版・年・出典、法・ガイド準拠インデックスを含む。
9. Wordに空欄指示、`undefined`、代替文字列が残らない。
10. 法律sourceが国勢調査sourceと同じURL、ファイル、hashではない。
11. データ収集の不足がある版を`collection.status: complete`と表示しない。
12. `npm run check`、`npm test`、国別検証、納品ゲート、実ブラウザ、Word全ページ確認を同じデータ版で通す。
