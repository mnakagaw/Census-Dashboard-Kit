# 4つの基準国ケース

国名だけで開始するAIは、次の4か国を同じ完成見本としてコピーしない。各ケースから指定された失敗防止策だけを取り出し、対象国の法制度、行政階層、統計定義、言語、資料公開状況へ適応する。

| 国 | このキットでの役割 | 必ず引き継ぐ教訓 | 引き継がないもの |
|---|---|---|---|
| ドミニカ共和国（DOM） | DDPTの原型 | 地域診断、テーマ比較、計画資料を結ぶ目的、地域選択の連動、計画と根拠資料の区別 | END、PMD、OMPP、SISMAP、自治体区分、承認状態などドミニカ共和国固有の制度 |
| ウガンダ（UGA） | 最初の本格的な国別適応 | 原表・全数値列の棚卸し、法定計画主体と内部分析地理の分離、Wordの根拠、代表地域から全国へ広げる回帰確認 | District、Subcounty、LGDP、NPA等の名称や階層を他国へ固定すること |
| ラオス（LAO） | 失敗回収と階層UXの基準 | 取得済み列の取り漏れ防止、指標別最新版、疎な階層、比較範囲と表示階層、地図ズーム、人口ピラミッド、Wordの図表・文章品質 | SEDPを一般名称にすること、全国値を地方値にすること、ADM2を一律にmunicipalityと呼ぶこと |
| バングラデシュ（BGD） | 全国カタログ完結の基準 | 代表1県で止めず公式カタログ全件を処理し、64県資料を最終状態へ振り分け、全国の地域・テーマ・出力を閉じること | Gazipurの表構造やUnion Parishadの制度を他国へ固定すること |

## 読む順序

1. ドミニカ共和国: [DDPT参照モデル](01_DDPT_REFERENCE.md)
2. ウガンダ: [ウガンダ2案件からの教訓](research/uganda-lessons-2026-09-14.md)
3. ラオス: [Antigravity初期版の監査](ANTIGRAVITY_LAOS_AUDIT_2026-09-15.md)と[理想形からの必須手順](LAOS_IDEAL_SAMPLE_LESSONS_2026-09-15.md)
4. バングラデシュ: [国別完成契約](COUNTRY_COMPLETION_CONTRACT.md)

機械可読の登録は`config/country-source-registry.json`の`reference_country_cases`に置く。生成される`evidence/SOURCE_PREFLIGHT.json`と`.md`にも4件を出し、AIがどの国から何を学ぶかを開始時に確認できるようにする。

## 完成と呼ぶ条件

4件が登録されているだけでは完成ではない。対象国の公式カタログ全件、全表・数値列、6分野、地理、計画制度、画面、CSV、Word、実ブラウザー、公開確認を対象国自身の根拠で閉じ、`verify-delivery`が`ready: true`になったときだけ完成とする。
