# Antigravity one-country wrapper

Open an empty Local project, grant project-scoped file/terminal/network/browser permissions, then use `prompts/ONE_COUNTRY_COMPLETE.md`. Change only `COUNTRY_NAME` and send it once. Antigravity must follow `GEMINI.md` and the shared completion contract; approving a command is continuation, not a new prompt.

Completion requires the delivery gate to report `ready: true`.
