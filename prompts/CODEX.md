Use `prompts/ONE_COUNTRY_COMPLETE.md`. Change only `COUNTRY_NAME` and send it once in a local Codex task opened on an empty output folder. Codex must follow `AGENTS.md` and `docs/COUNTRY_COMPLETION_CONTRACT.md`, continue through browser and Word verification, and finish only when the delivery gate reports `ready: true`.

All 250 world-registry countries and areas are valid starts. Read `config/world-source-preflight.json` first; use the JICA 142 record as a supplement when present. DOM, UGA, LAO and BGD are valid fresh targets as well as reference lessons. Replay a matching Americas recipe before generic search, then refresh and re-acquire current sources. Historical recipes and discovery addresses are not current-project evidence. Create a new output and do not return a stored example.
