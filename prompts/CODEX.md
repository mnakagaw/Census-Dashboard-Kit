# Codex one-country wrapper

Use `prompts/ONE_COUNTRY_COMPLETE.md`. Change only `COUNTRY_NAME` and send it once in a local Codex task opened on an empty output folder. Codex must follow `AGENTS.md` and `docs/COUNTRY_COMPLETION_CONTRACT.md`, continue through browser and Word verification, and finish only when the delivery gate reports `ready: true`.

DOM, UGA, LAO and BGD are valid target countries as well as reference lessons. For any of the 142 priority countries, read its `config/jica-priority-source-preflight.json` record. If `config/americas-verified-source-recipes.json` has a matching country/area, replay that method before generic search, then refresh and re-acquire the current sources. Historical recipes are not current-project evidence. Create a new output and do not return a stored example.
